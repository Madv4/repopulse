# RepoPulse coding conventions

- Work through the user-defined phases in order. Run lint, type checking and tests, then commit each completed phase before starting the next.
- Keep all unit tests and CI deterministic. Inject HTTP transports and never call live GitHub or LLM services from tests.
- Keep credentials in environment variables or `.env`; never commit `.env`, tokens, caches, or traces. Never include tokens in exceptions or logs.
- Type all public functions and use Pydantic for structured application data.
- Keep `LLM_PROVIDER=mock` usable without network access.
- Do not claim evaluation metrics unless generated by a real run of the evaluation suite.
- Source code lives in `src/repopulse`; tests live in `tests`; architecture and phase decisions live in `docs/DESIGN.md`.
